# ASH Asset Library

Central visual asset library for the ASH overseas B2B website.

## Structure

- `brand/` — approved or working brand marks and reusable ASH visual elements.
- `products/` — real product photography and web-ready derivatives.
- `packaging/` — ASH packaging photography, box views and presentation assets.
- `reference/` — art-direction boards and design references. These are references, not production imagery.

## Source-of-truth rule

The GitHub repository is the working source for website assets. Historical ChatGPT uploads are treated as the original source library until their binary originals are transferred here.

Do not replace real product photography with generated renders when a real ASH product image exists.

## Naming

Use lowercase, hyphenated names and stable suffixes such as `-01`, `-02` for alternate views.

## Current core assets

The initial library includes the reusable ASH leaf, water, mechanical and feature SVG family. The next production pass should keep real product photography and the approved packaging-derived ASH mark under the same library structure.
