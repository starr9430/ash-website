## Important rule

These are source photographs, not website-ready compositions.

It is completely fine if:
- the background is white
- the photo contains empty margins
- several components appear together
- the angle is not ideal

The website layer will create:
- clean cutouts
- transparent PNG/WebP derivatives
- controlled shadows
- editorial three-quarter compositions
- thumbnails and detail crops

Do not pre-design the website composition in the source files.
