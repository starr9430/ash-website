# ASH Asset Library v0.1

The first reusable asset layer for the ASH website.

## Brand motifs

- `leaf-vein.svg` — organic branching / growth language
- `water-ribbon.svg` — movement / continuity language
- `footer-leaf.svg` — large-scale closing motif

## Industrial motif

- `mechanical-ring.svg` — technical geometry, measurement and mechanical structure

This is intentionally an abstract structural graphic, not a substitute for real product photography.

## Feature icons

- `icon-reliability.svg`
- `icon-materials.svg`
- `icon-coverage.svg`
- `icon-supply.svg`

The icon family uses the same thin-line language and restrained petrol / moss palette.

## Usage rules

### Water

Use as a large flowing layer behind or beside the product. It should create movement, not become a decorative border.

### Leaf

Use as a cropped organic silhouette, vein structure or large line-art form. Never surround a product with leaves.

### Mechanical ring

Use sparingly as a technical framing device, measurement cue, or background structure.

### Icons

Keep small. Use them to convert the emotional Hero into practical B2B information.

### Footer leaf

Treat as a structural signature at the edge of the dark footer, not as a logo.

## Current status

These SVGs are **structural brand assets v0.1**. They establish the visual language and are suitable for layout experimentation.

For launch, replace placeholders with:

- approved ASH logo artwork
- real clutch product photography
- real material photography / texture captures
- production-approved brand colors if the final color specification changes
